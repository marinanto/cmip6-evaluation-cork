# Input data

Place the required NetCDF files in `data/new_eraland/`:

- `era5_land_cork_1985_2025_final.nc`
- `cnrm_ref_final.nc`
- `hadgem_ref_final.nc`
- `ecearth_ref_final.nc`
- `cnrm45_final.nc`
- `cnrm85_final.nc`

Place the four station Excel files in `data/stations/`:

- `mly575.xlsx` - Moore Park
- `mly775.xlsx` - Sherkin Island
- `mly1075.xlsx` - Roches Point
- `mly3904.xlsx` - Cork Airport

Station files must contain `year`, `month` and `meant` columns.

Before publishing the repository, add the source, version/DOI, access information and licence for every dataset. Do not redistribute datasets unless their terms permit it.
