# CMIP6 GCM evaluation and bias correction for local-scale climate applications in County Cork, Ireland

This repository contains the reproducible R workflow accompanying the manuscript. The analysis evaluates CNRM, HadGEM and EC-Earth over 1985-2014, selects CNRM using complementary performance criteria, applies regression-based statistical bias correction, and validates the resulting SSP2-4.5 and SSP5-8.5 simulations over 2015-2025 against ERA5-Land and four Met Éireann stations.

## Repository structure

```text
R/cork_analysis_9km.R   # single master analysis script
data/                    # input data, subject to source licences
outputs/figures/         # manuscript figures generated by the script
outputs/tables/          # manuscript tables generated by the script
docs/                    # reproducibility notes
```

## Run

Run the master script from the repository root:

```r
source("R/cork_analysis_9km.R")
```

The script expects the input files documented in `data/README.md`.

## Error convention

Signed errors are calculated consistently as reference minus GCM:

- gridded evaluation: ERA5-Land - GCM
- station validation: station observation - GCM

## Data

Raw climate and observational data should only be uploaded when their source licences permit redistribution. Otherwise, keep the data out of the public repository and document their provenance and access instructions in `data/README.md`.
